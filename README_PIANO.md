# Piano TSR Program

这是一个使用汇编语言编写的键盘中断驻留程序 (TSR)。

## 功能
- **F1 键**: 切换“钢琴模式”的开关。
- **钢琴模式**:
  - 键盘上的 `A` `S` `D` `F` `G` `H` `J` `K` 键分别对应音符 Do, Re, Mi, Fa, Sol, La, Si, Do。
  - 按下键发声，松开键停止。
  - 在此模式下，这些键不会在屏幕上输入字符。
- **正常模式**: 键盘功能恢复正常。

## 编译与运行 (在 DOSBox 中)

**编译**:
   ```bash
   build.bat
   ```
   *链接器会警告 "No stack segment"，这是正常的，因为生成的是 .COM 文件。*
   程序运行后会驻留在内存中。
   
**运行**:
   ```bash
   piano.com
   ```

## 使用方法
1. 运行 `piano.com`。
2. 屏幕显示安装成功信息。
3. 按 **F1** 键开启钢琴模式。
4. 按 `A` `S` `D` ... 演奏。
5. 再次按 **F1** 键关闭钢琴模式，恢复正常打字。

## 源代码说明
- 使用 `INT 09h` 截获键盘中断。
- 使用 `INT 27h` 实现驻留。
- 直接操作端口 `60h` 读取扫描码。
- 直接操作端口 `61h` 和 `42h`/`43h` 控制 PC 喇叭发声。
